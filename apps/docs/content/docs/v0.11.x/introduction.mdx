# Better Auth for PayloadCMS 🔐

You are one plugin away from revolutionizing your PayloadCMS's authentication system. This plugin seamlessly integrates [Better Auth](https://www.better-auth.com) with [Payload CMS v3](https://payloadcms.com), providing enhanced authentication capabilities.

## Key Features 🎯

<Tabs>
  <Tab value="authentication" title="Authentication">
    <ul>
      <li>Unified Better Auth strategy: email + password, TOTP 2FA, social/OAuth, passkeys</li>
      <li>Default email verification and password reset flows (overridable)</li>
      <li>Session management handled by Better Auth</li>
      <li>Role-based access control via the Better Auth admin plugin</li>
    </ul>
    <Link href="features/two-factor">Two-factor authentication</Link>
  </Tab>
  <Tab value="admin-ui" title="Admin UI">
    <ul>
      <li>Auto-injected social login buttons in the Payload admin login screen</li>
      <li>2FA setup prompt before the dashboard, plus setup/verify views</li>
      <li>Account-level controls (TwoFactorAccountButton)</li>
    </ul>
    <Link href="features/social-login">Social login</Link>
  </Tab>
  <Tab value="developer-experience" title="Developer Experience">
    <ul>
      <li>Collections auto-generated from your Better Auth options</li>
      <li>Payload endpoints bridged to Better Auth (`/login`, `/logout`, `/me`, ...)</li>
      <li>Per-collection overrides via `extendsCollections`</li>
      <li>Auth layer helpers for Next.js (checkers, guards, server actions)</li>
    </ul>
    <Link href="api/exports">API Reference</Link>
  </Tab>
</Tabs>
